#+TITLE: rocq-mode.el

=rocq-mode= is an Emacs mode for the Rocq theorem prover, using [[https://github.com/ejgallego/coq-lsp][coq-lsp]] under
the hood, licensed under the GPLv3 or later.

Only the latest =coq-lsp= version (2.5.0) is supported.

This package depends on [[https://github.com/joaotavora/eglot][Eglot]] for its LSP support.

* Features
- Structured goal display;
- Processing overlay indicator;
- Displaying of slow commands;
- Automatic addition of folders containing a ~_RocqProject~ or ~_CoqProject~ file to the workspace;
- Instant switching between on-demand and continuous mode;
- Indentation of proofs, bullets, =match= branches and terms;
- Motion by sentence with =M-a= and =M-e=;
- Queries such as =Search= and =Check= at point, without editing the file;
- Misc. =coq-lsp= commands like ~rocq-trim~, ~rocq-save-vo~ and ~rocq-reload-vos~.

* Using =rocq-mode=
Whenever =rocq-mode= requests the proof status at point, it updates the goal
buffer, =*Rocq Goal*=.  Its header line says which goal is shown and how many
goals are open, focused or not, and the buffer shows the selected goal in full,
with the error of the sentence at point if it failed and any messages below.
=C-c C-n= and =C-c C-p= (~rocq-next-goal~, ~rocq-previous-goal~) cycle through
the focused goals from the Rocq buffer.

=C-c C-c= (~rocq-switch-to-goals~) switches the goal buffer to a summary with
one line per goal and moves there.  In the summary, =n= and =p= move the
selection,
=RET= or a digit selects a goal, which shows it in full and returns to the Rocq
buffer, and =q= returns without changing the selection.  Unfocused goals, those
outside the current bullet or braces, are only counted unless =s f= lists them
around the focused ones; shelved and given up goals likewise with =s s=.  =TAB=
switches between the two views from inside the goal buffer.  The selection
follows the same goal across refreshes while it exists.

The goal buffer is only displayed by commands you invoke explicitly, such as
~rocq-request~, ~rocq-switch-to-goals~ or selecting a goal; automatic refreshes
update it in place if it is visible and leave your windows alone otherwise.  Set
~rocq-display-goals~ to ~always~ to have every refresh display it.  Where it is
displayed can be customized with ~display-buffer-alist~, for instance to keep it
in a side window:
#+begin_src emacs-lisp
  (add-to-list 'display-buffer-alist
               '("\\*Rocq Goal\\*" display-buffer-in-side-window (side . right)))
#+end_src

* Queries
=C-c C-a= prefixes queries that run at the state of the sentence at point,
without touching the file, and show their output in the =*Rocq Query*= buffer.
The bindings follow Proof General: =C-c C-a C-a= or =C-c C-a C-s= for =Search=,
=C-c C-a C-o= for =SearchPattern=, =C-c C-a C-c= for =Check=, =C-c C-a C-p= for
=Print=, =C-c C-a C-b= for =About= and =C-c C-a C-l= for =Locate=, which quotes
notations for you.  Each prompts with the identifier at point as default and
keeps its own history, and a prefix argument runs =Check=, =Print= and =About=
under =Set Printing All=.  In the query buffer, =n= and =p= move between
results, =RET= runs =About= on the result at point, =i= inserts its name in the
Rocq buffer, =w= copies it, =g= runs the query again and the =C-c C-a= commands
work at the position of the query.  Queries need coq-lsp 0.2 or later, whose
Petanque API runs them.

* Indentation
=TAB= indents the current line and =M-x indent-region= a region, following the
structure of the code: proof bodies, bullets and braces in proofs, =match=
branches, =fun= and =let= bodies, and the contents of brackets.  Sentences are
recognized without a parser, so unusual notations may occasionally fool it.
Four options control the layout:
- ~rocq-indent-offset~ (default 2) is the indentation of continuation lines,
  branch bodies and nested bullets;
- ~rocq-indent-proof-offset~ (default 2) is the indentation of tactics relative
  to =Proof=; set it to 0 for the style where tactics start in column zero;
- ~rocq-indent-match-offset~ (default 0) shifts =|= branches relative to their
  =match=;
- ~rocq-indent-sections~ (default ~nil~) indents the contents of sections and
  modules.
Typing =|= or =}= at the start of a line reindents it.

* Sentences
=M-e= (~rocq-forward-sentence~) moves to the end of the current sentence and
=M-a= (~rocq-backward-sentence~) to its start, or to the previous one when
already there.  Both take a count.  A sentence ends at a period followed by
whitespace; as in Proof General, a bullet and each brace of a proof block are
sentences of their own, and comments are skipped.  The =..= of recursive
notations is not a terminator.  On Emacs 30 and later, =M-k=
(~kill-sentence~) and the other sentence commands follow the same rules.

* Configuration
The recommended configuration is via ~use-package~ (see [[https://www.gnu.org/software/emacs/manual/html_mono/use-package.html][use-package's
documentation]]), using the ~:vc~ keyword.  Here is an example configuration
enabling ~rocq-mode~ by default with =.v= files, as well as enabling viewport
following and automatic goal request.
#+begin_src emacs-lisp
  (use-package rocq-mode
    :vc (:url "https://codeberg.org/jpoiret/rocq-mode.el.git"
         :rev :newest)
    :mode "\\.v\\'"
    :hook
    (rocq-mode . rocq-follow-viewport-mode)
    (rocq-mode . rocq-auto-goals-at-point-mode)
    :custom
    ;; Whether to show the goal above the context, default is `t`
    (rocq-top-goal t))
#+end_src

~rocq-follow-viewport-mode~ is a minor mode that sends viewport notifications to
=coq-lsp=, so that it will process only what is visible.

~rocq-auto-goals-at-point-mode~ is a minor mode that automatically asks for goal
display at point after idling for ~rocq-mode-idle-goals-delay~.  Feel free to
liberally toggle it to make the corresponding goal window keep its current
display.  You can also use ~rocq-request~ (bound to =C-c C-,= by default) to
manually request goal display.

You can customize ~rocq-top-goal~ to display the goal conclusion above or below
the context.

By default, entering ~rocq-mode~ starts a =coq-lsp= server for the current
project if there is none yet.  Set ~rocq-mode-start-server~ to ~nil~ to start
servers yourself instead: requesting the goals with =C-c C-,= (~rocq-request~)
starts the server of the current project if it is not running, as does =M-x
eglot=; files you then open in a project whose server is already running are
picked up by it automatically.  A server can be stopped with =M-x
eglot-shutdown= (or =M-x eglot-shutdown-all=), and setting Eglot's
~eglot-autoshutdown~ to ~t~ stops a server automatically once the last buffer it
manages is killed, which avoids accumulating idle servers.

If you want to turn off on-demand checking (to go back to continuous mode), use
~rocq-toggle-check-on-request~.  To highlight slow commands, use
~rocq-toggle-timing-data~, and to toggle whether the goals being requested are
shown before or after the sentence under point is executed, use
~rocq-toggle-goal-after-tactic~.  Note that these changes are global to the
=coq-lsp= session.  You can change the default slots of ~rocq--lsp-server~
corresponding to these options using ~oset-default~, but note there is no
analogue of ~setq-local~ for this, so these changes are global and not
retroactive on started =coq-lsp= sessions.

* Projects
=coq-lsp= only looks for project files at the root of its workspace folders.
Besides the folder of the current project (as determined by =project.el=),
=rocq-mode= registers, for every Rocq file you open, the nearest directory above
it containing one of the files in ~rocq-project-files~ (by default
~_RocqProject~ or ~_CoqProject~), so that nested projects get their own flags.

If your layout is different, you can set ~rocq-project-root-function~ to a
function returning the project root of the current buffer, or set
~rocq-project-root~ for a specific project with a =.dir-locals.el= file:
#+begin_src emacs-lisp
  ((rocq-mode . ((rocq-project-root . "../theories/"))))
#+end_src

Folders can also be added and removed by hand with ~rocq-add-workspace-folder~
and ~rocq-remove-workspace-folder~.

* Development
=make compile= byte-compiles the package with warnings treated as errors, and
=make test= runs the ERT suite in =test/=.  The suite exercises project root
registration, server start and shutdown, goal display, indentation, sentence
motion and comment filling.  The server tests run against =test/fake-lsp.py=, a small LSP server
standing in for =coq-lsp=, and are skipped when =python3= or =git= is not
available.
